# Equality News

An independent community roleplay news station. This station is not official or endorsed by the actual Equality Studios or its founder.

Equality News includes searchable station stories, separate article pages, an accessible Learn More control, and a device-based Popular section.

Update `content/stories.json` and commit to `main` to rebuild and publish through GitHub Pages. See [MAINTENANCE.md](MAINTENANCE.md) for story and asset guidance. The original site ZIP is retained as an archive.
